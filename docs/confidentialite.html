Chatbot Fabric Mastery est un projet indépendant édité par Antoine Wang, adossé à la newsletter Fabric Mastery. Cette page décrit concrètement ce qui est traité, où, et pendant combien de temps.

L'essentiel : aucun compte n'est créé, aucun traceur publicitaire n'est déposé, et le texte de vos questions n'est jamais écrit dans les journaux du service.

Où vos questions transitent

Pour produire une réponse, votre question est envoyée à Azure OpenAI, dans la région Suède Centre (Union européenne). Le service est hébergé sur Azure Container Apps, dans la même région.

Azure OpenAI applique un dispositif de surveillance des abus propre à la plateforme Microsoft, qui peut conserver les invites et les réponses pendant une durée limitée (jusqu'à 30 jours) afin de détecter les usages abusifs, sauf exemption accordée par Microsoft. Ce traitement relève de Microsoft en tant que fournisseur de la plateforme. Voir la documentation Microsoft sur les données Azure OpenAI.

Vos questions ne sont pas utilisées pour entraîner un modèle, ni revendues, ni transmises à un tiers à des fins commerciales.

Cookies et mesure d'audience

L'application n'utilise ni cookie publicitaire ni traceur tiers. Le framework Streamlit maintient un état de session technique, strictement nécessaire au fonctionnement du chat. La page d'accueil est un fichier statique servi par GitHub Pages ; GitHub peut journaliser les accès à ses propres fins d'exploitation.

Sources et propriété intellectuelle

Les réponses sont construites exclusivement à partir des éditions publiées de la newsletter Fabric Mastery, dont le contenu reste la propriété d'Antoine Wang. Le code source est publié sous licence MIT.

Limites du service

L'assistant est un outil d'aide fondé sur un modèle de langage. Malgré une conception qui n'autorise que des réponses sourcées, des erreurs restent possibles. Vérifiez toujours via les sources citées avant toute décision d'architecture ou de production. Le service est fourni en l'état, sans garantie.

Vos droits et contact

Puisque aucun compte n'est créé et qu'aucun identifiant personnel n'est conservé côté service, il n'existe pas de profil utilisateur à consulter ou supprimer : effacer la conversation ou fermer l'onglet suffit à supprimer les données de session.

Pour toute question relative à ces traitements, ou pour exercer vos droits au titre du RGPD, répondez à n'importe quelle édition de la newsletter ou ouvrez un ticket sur le dépôt GitHub.
